# KAILAS Кыргызстан — интернет-магазин

Сайт магазина горной одежды и снаряжения KAILAS для Кыргызстана (версия 1, русский язык).

## Как открыть

```bash
python3 -m http.server 8420 --directory ~/kailas-kg
```

Затем откройте http://localhost:8420

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Шапка, подвал, корзина |
| `css/styles.css` | Дизайн (чёрно-белый стиль KAILAS, адаптив под телефон) |
| `js/config.js` | **Контакты, адрес, WhatsApp, стоимость доставки, список стран** — заполните реальные данные |
| `js/products.js` | Каталог товаров, цены (в сомах), курсы валют |
| `js/i18n.js` | Тексты интерфейса. Блоки `ky` и `en` пустые — для кыргызской и английской версий |
| `js/art.js` | Иллюстрации-заглушки товаров (пока нет фото) |
| `js/app.js` | Логика: страницы, фильтры, корзина, оформление заказа |

## Что уже работает

- Главная (слайдер, баннеры, активности, хиты, новинки, истории, магазин)
- Каталог с фильтрами (категория, пол, активность, цена), сортировкой и поиском
- Карточка товара: цвет, размер, количество
- Корзина (сохраняется в браузере), прогресс до бесплатной доставки
- Оформление заказа: 37 стран, зоны доставки КР / СНГ / мир, способы оплаты
- Валюты: KGS, USD, RUB, KZT
- Страницы: О нас, Контакты, Доставка и оплата, Возврат, Таблица размеров, FAQ

## Что нужно для запуска «вживую»

1. **Фото товаров** — положить в `img/products/` и прописать поле `img` у товара в `products.js`.
2. **Онлайн-оплата** — подключить платёжный шлюз, работающий в КР (например Freedom Pay / PayBox, MBank, Optima). Место в коде: `// TODO` в `pageCheckout` в `app.js`.
3. **Приём заказов** — сейчас заказ сохраняется в браузере покупателя и предлагается отправить в WhatsApp. Нужен сервер/CRM или хотя бы Telegram-бот для уведомлений.
4. **Хостинг и домен** (например kailas.kg).
5. **Переводы** — заполнить `ky` и `en` в `i18n.js` и включить в `LANGS_ENABLED`.
